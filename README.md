# HogarQuest 🏡⭐

App familiar para organizar las tareas de casa como un juego. Cada persona usa su móvil y todos ven las puntuaciones de todos.

## Qué incluye

- **Misiones** diarias, semanales o de una vez, con revisión opcional de un adulto.
- **Juego**: puntos, niveles, rachas, logros, ruleta diaria, cofres, combos y retos.
- **Avatares** personalizados, con accesorios que se desbloquean por nivel.
- **Tienda de premios** y ranking familiar con meta semanal.
- **Panel de adultos** para gestionar tareas, puntos, premios y familia.
- **Familia compartida** entre móviles, con funcionamiento sin internet.

## Instalar

- **Android**: instala el APK.
- **iPhone**: abre la web de la app en Safari y pulsa Compartir → **Añadir a pantalla de inicio**.

## Estructura

- `src/`: la app
- `server/`: servidor de sincronización
- `public/`: archivos de la web instalable
- `android/`, `ios/`: proyectos nativos
- `render.yaml`: publicación en Render
- `build-android.ps1`: genera el APK
